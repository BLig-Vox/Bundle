# Consumed MikroORM domain generators

## Intent and architecture

Implement bounded Bun equivalents for make:factory/cast/scope/observer using the already installed aligned MikroORM7 packages. Native ORM APIs are consumers, but generator output must strictly compile and execute against disposable real SQLite before credit. No packages/network/server provisioning, markup/decorators/schema DSL, real databases or commits. These leader-selected choices continue the standing implementation directive, not Laravel/PHP interoperability.

## Generator contract

Add generateDatabaseScaffold(root,kind,name,options?) to the existing scaffolding infrastructure and register four public commands without loading database settings/connecting. PascalCase slash namespaces, computed aliased imports, exclusive/no-symlink writes and trusted consumed custom stubs follow current foundations. No force overwrite or automatic model modification/registration.24 total stubs.

- make:factory Billing/UserFactory --model User emits database/factories/Billing/UserFactory.ts extending @mikro-orm/seeder Factory<User>, importing the explicit top-level existing src/models/User.ts named class with computed relative import. --model is required, top-level validated PascalCase; model source must be bounded regular single-link/no symlink with named class/default schema exports present (syntactic export scan is not sandbox/model validity proof). Do not execute model imports during generation. Aliased TypeScript imports avoid generated-name collisions. model is User; definition(input?:EntityData<User>):EntityData<User> requires explicit input and returns copied supplied attributes, throwing generically when missing. This deliberate default supplies no fake schema-specific fields/Faker/decorators; callers customize defaults or pass valid attributes and may use native each(). Actual factory createOne must persist/flush a real model. Stub tokens name/modelName/modelImport.
- make:cast Billing/TrimmedText emits src/database/types/Billing/TrimmedText.ts extending aliased native Type<string,string>. Explicit example validates strings, trims on database conversion and preserves stored string on JS conversion; getColumnType delegates to platform text declaration. Types/imports aliased; explicit EntitySchema property mapping consumes it. No global model edits or Eloquent cast API claim. Stub token name only.
- make:scope Billing/NamedUsers emits src/database/scopes/Billing/NamedUsers.ts as a named generic async helper accepting EntityManager, EntityName<T>, FilterQuery<T> and returning actual em.find(entity,where,{limit:100}). Example limit is explicit and customizable, not global scope/automatic policy. Native types aliased. Stub token name only.
- make:observer Billing/RecordCreates emits src/database/observers/Billing/RecordCreates.ts implementing native EventSubscriber with own afterCreate(args:EventArgs<object>) and instance createdCount counter. Example observation only; replace business logic and explicitly register instance using the actual EventManager. No automatic discovery or lifecycle registration at module import. Native types aliased. Stub token name only.

Required stub tokens/unknown tokens/TS syntax remain validated. Collision names including Factory/EntityData/Type/EntityManager/EventSubscriber compile where existing common-type name rules permit; preserve existing reserved-name refusals rather than weakening global validation. Add no decorative runtime wrappers: consume native Factory/Type/find/EventSubscriber directly and document exact differences.
